# Meridian Freight Systems: Employee Handbook (leave sections)

Synthetic handbook for a fictional mid-size US logistics company with employees in California, New York and Ohio. Written to read like a real handbook: uneven in tone, vague in places, silent on things a real one would omit.

**This is the company layer of the corpus.** It sits below statute in the precedence hierarchy: it may exceed a statutory floor but may never reduce one.

`DEFECTS.md` in this directory records which policies carry deliberate faults and what the correct resolution is. **That file is ground truth and must never be ingested or shown to the agent.**

Each policy is a separate file so it can be versioned and effective-dated independently, which is also what makes supersession testable.
